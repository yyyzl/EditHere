## 纳入范围

- 图片、视频帧反馈采用 `feedback-minimal-3` 对象：`kind` 区分区域、点和全局，批注保留编号和文件内对象 ID。
- 位移只保存单个最终 `movement`，坐标整数化、缩放最多两位小数，兼容读取旧 `result` / `movements`。
- 反馈默认使用同目录原图，包含尺寸、MIME 和 SHA-256；支持内嵌、仅原图描述及编号 JPEG。视频配套帧图片、CLI 和 MCP 回执同步处理。
- AI 可提供 `pageContext`，显示并随工程、反馈、视频帧保留；导入保留原始文件名。
- 位移批注删除第一次点击生效；删除恢复对应组件的位置和尺寸，支持撤销，保留独立移动的子组件。
- 同步反馈坐标边界校验、翻译、桌面/Web/CLI/MCP/Schema 及相关回归测试。
- Linux AppImage runtime 固定版本，并附带离线 CLI 预览需要的 offscreen 插件。

## 明确不恢复

系统截图、长截图、置顶贴图、系统全局快捷键、窗口信息自动采集和自动 OCR 均不恢复。不恢复相关平台依赖、控制器状态机或专用测试。

仅兼容导入文件中已有的区域文字：可保留、编辑、删除及选择是否导出，不能把文字当作额外指令。

白板空白启动、托盘恢复、macOS Dock 重开、模板菜单栏图标及已签名 DMG 元数据保护继续保留；更新仍指向 `yyyzl/EditHere`。

## 兼容性提醒

旧反馈与项目继续可读，但旧应用不保证能读取新 v3 反馈。默认导出不再是单文件自包含 JSON，应将 JSON 与配套原图一起交付；需要单个文件时使用 `--embed-image`。`--no-image` 只保留原图描述，接收方必须已有原图。`--preview` 另外输出编号 JPEG，不能代替原图。

```text
edithere-cli annotate <图片绝对路径> --output <尚不存在的反馈.json> --page-context "页面说明"
edithere-cli export <工程绝对路径> --output <尚不存在的反馈.json> --embed-image --preview
```

## 第二选区问题

桌面大爆炸中，旧选区包含新区域时，原逻辑将内部点击直接归为旧选区拖动。现在单击松开且未发生布局变化时允许切换内部候选；真正拖动仍移动原选区，边缘缩放不变，Ctrl 可切换内部区域的多选。

回归覆盖 0.5、1、2 倍缩放下“选大框 → 写第一条批注 → 单击内部另一块 → 写第二条批注”，以及父区拖动、Ctrl 多选。该修复覆盖已确认的代码路径，不代表所有概率性选区问题均已复现；若实际操作仍异常，需要录屏或素材继续定位。
