EditHere 0.12.0 · Annotation whiteboard

Launch to an empty workspace, paste, drop or open an image, then annotate, adjust layouts, save and send feedback to AI. Launching again or clicking the tray restores the current work.

- Remove system screenshots, OCR, scrolling capture, pinning, and their global shortcuts, settings, platform APIs and dedicated dependency source.
- Keep smart/point/rectangle/global annotations, component movement and scaling, projects, JSON and annotated-image export.
- Keep CLI, MCP and skills; screenshot commands are removed. The whiteboard has separate communication endpoints, and agents should use its bundled CLI.
- Remove the old screenshot demo recorder and 16 screenshot-only icons, update Linux packaging dependencies and bilingual documentation.
- GitHub Actions builds Windows, universal macOS (Apple Silicon / Intel), Linux and Web from the same source. Updates use this repository's Releases.

The macOS app uses an ad-hoc signature and is not Apple-notarized; Gatekeeper may require permission to open it. Screen recording and accessibility permissions are not required. Project and feedback JSON formats are preserved.
