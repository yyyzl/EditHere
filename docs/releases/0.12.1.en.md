EditHere 0.12.1 · macOS menu bar icon

The EditHere icon in the macOS menu bar now uses a system template image for a consistent monochrome appearance. macOS adapts its light and dark rendering to the menu bar background and selection state.

Windows, macOS universal (Apple Silicon / Intel), Linux, and Web packages continue to include the annotation whiteboard features introduced in 0.12.0.

The macOS app remains ad-hoc signed and is not notarized by Apple. Gatekeeper may require permission to open it.
