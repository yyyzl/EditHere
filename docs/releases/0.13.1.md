EditHere 0.13.1 · 未保存内容保护与视频待机修复

本次为修复版本，重点避免未保存内容意外丢失，并停止隐藏窗口后的后台视频播放。

### 未保存内容保护

- **Web 反馈导入**：导入 JSON 后补选配套图片时，会重新检查当前未保存修改。取消替换后，原素材、批注及撤销/重做记录保持不变；确认后才导入新反馈。
- **桌面关闭提醒**：勾选“不再提醒”后，如果取消关闭、取消保存或保存失败，后续关闭仍会提醒。只有成功保存或明确选择放弃后，才记住这项设置。

### 视频待机修复

- 关闭 AI 视频批注窗口到托盘时，暂停正在播放的视频，避免隐藏后仍在后台播放。
- 保留素材、批注、播放位置和已暂停画面的撤销记录；恢复窗口后可手动继续播放。

离线 Web 包与 Web Agent/MCP 包已同步修复。本版不改变反馈或项目格式，不包含新的自动更新流程。

macOS 应用仍为临时签名，尚未 Apple 公证，首次打开可能需要系统授权。升级前请保存工作并完全退出旧版。
