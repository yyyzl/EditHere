EditHere 0.13.1 · Unsaved-work protection and background video fixes

This maintenance release prevents accidental loss of unsaved work and stops video playback behind a hidden annotation window.

### Unsaved-work protection

- **Web feedback imports**: selecting a missing companion image now checks again for unsaved changes in the current document. Cancelling keeps the original media, annotations and undo/redo history intact; the new feedback is imported only after confirmation.
- **Desktop close reminders**: selecting “Do not remind again” no longer disables future reminders if you cancel closing, cancel the save dialog or encounter a save failure. The preference is committed only after a successful save or an explicit discard.

### Background video fix

- Closing an AI video annotation window to the tray now pauses active playback instead of leaving the video playing in the background.
- Media, annotations, playback position and the undo history of an already paused annotation frame are preserved. Playback can be resumed manually after reopening the window.

The offline Web and Web Agent/MCP packages include the same fixes. Feedback and project formats are unchanged. A new automatic-update flow is not included in this release.

The macOS app remains ad-hoc signed and is not notarized by Apple; Gatekeeper may require permission to open it. Save your work and quit the previous version completely before upgrading.
