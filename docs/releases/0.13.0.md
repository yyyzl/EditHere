EditHere 0.13.0 · 白板反馈与选区修复

### 大爆炸选区修复

- 修复先选中大区域、写完第一条批注后，内部第二个区域无法单击选中的问题。
- 单击可以切换内部区域；真正拖动仍移动原选区，边缘缩放不变，Ctrl 可切换内部区域的多选。
- 同步修复位移批注第一次点击删除不生效；删除后恢复组件位置和尺寸，支持撤销，并保留独立移动的子组件。

### 更清晰的 AI 反馈

- 采用 `feedback-minimal-3`，保留界面批注编号和对象 ID，明确区分区域、点和全局意见。
- 每个移动对象只保存一个最终目标，减少重复数据；坐标整数化，缩放最多两位小数。
- 支持页面说明、原图尺寸与 SHA-256 校验、编号 JPEG；桌面、Web、CLI、MCP 和视频帧使用一致的反馈结构。
- 旧反馈和项目继续可读；旧版本应用不保证能读取新 v3 反馈。

### 导出方式变化（重要）

**默认导出 JSON 与配套原图，请将它们一起交给 AI。** 需要单个自包含 JSON 时使用 `--embed-image`；`--no-image` 仅保留原图描述，接收方必须已有原图；`--preview` 另外生成编号 JPEG，不能代替原图。

### 保持精简白板

不恢复系统截图、长截图、置顶贴图、全局快捷键或自动 OCR。仅保留、编辑导入文件中已有的区域文字。继续保留 macOS Dock 重开、单色菜单栏图标和标准 DMG 拖拽安装修复；Linux AppImage runtime 固定版本。

macOS 应用仍为临时签名，尚未 Apple 公证，首次打开可能需要系统授权。升级前请完全退出旧版。
