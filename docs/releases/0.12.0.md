EditHere 0.12.0 · 纯批注白板

打开应用直接进入空白工作台，自己粘贴、拖入或选择图片，然后批注、调整布局、保存和交给 AI。再次打开或点击托盘会恢复当前编辑内容。

- 移除系统截图、OCR、长截图、贴图及对应全局快捷键、设置、平台接口和专用依赖源码。
- 保留智能选块、点／框／全局批注、组件移动与缩放、项目保存、JSON 和批注图片导出。
- 保留 CLI、MCP 和 skill 接入；截图命令已删除。旧版与白板使用独立通信通道，AI 请使用白板包内的 CLI。
- 删除旧截图演示录制器与 16 个截图专属图标，更新 Linux 打包依赖及中英文说明。
- Windows、macOS universal（Apple Silicon / Intel）、Linux 和 Web 均由 GitHub Actions 从同一源码构建。更新来源为本仓库 Releases。

macOS 应用仍为临时签名，尚未 Apple 公证；系统 Gatekeeper 可能需要用户授权打开。白板不需要屏幕录制或辅助功能权限。项目及反馈 JSON 结构保持原有格式。
