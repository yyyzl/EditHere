EditHere 0.12.3 · 标准 macOS 拖拽安装

DMG 安装窗口现在只显示两个入口：左侧 EditHere，右侧 Applications（应用程序），中间箭头引导拖拽安装。把 EditHere 拖过去，再从「应用程序」启动即可，安装后可以推出磁盘。

- 说明、许可、AI 技能、数据格式与版本信息全部放入应用包，随应用一起安装。
- 保留包内 CLI，AI 接入路径保持为 `EditHere.app/Contents/MacOS/edithere-cli`。
- 对最终 DMG 做真实挂载检查，并在复制应用、推出磁盘后验证签名及 CLI 运行。
- 保留 Dock 恢复窗口和灰白菜单栏图标修复，更新纯批注白板使用说明。

升级前请先完全退出旧版，再替换「应用程序」中的 EditHere。macOS 应用仍为临时签名，尚未 Apple 公证，首次打开可能需要系统授权。同步提供 Windows、Linux 和 Web 包。
