EditHere 0.12.2 · Restore the macOS window from the Dock

Fixed a macOS issue where closing the whiteboard window left the app running, but clicking its icon in the Dock did not reopen the window. The Dock now restores the whiteboard without requiring you to quit and relaunch the app.

- Handle macOS application reactivation, including repeated close and reopen cycles.
- Keep login and AI background launches hidden during initial activation.
- Reuse the existing window activation, save confirmation, and AI session handling.
- Retain the monochrome menu bar icon introduced in 0.12.1.

Windows, macOS universal (Apple Silicon / Intel), Linux, and Web packages are included. The macOS app remains ad-hoc signed and is not notarized by Apple; Gatekeeper may require permission to open it.
