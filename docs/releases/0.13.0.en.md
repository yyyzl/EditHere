EditHere 0.13.0 · Whiteboard feedback and selection fixes

### Explode selection fixes

- Fixes clicking a second region inside a previously selected large region after writing the first annotation.
- A click can switch to a nested region; dragging still moves the original selection, resize handles keep their behavior, and Ctrl toggles nested multi-selection.
- Fixes movement annotation deletion on the first click. Deleting restores the component's position and size in one undoable operation while preserving independently moved children.

### Clearer AI feedback

- Uses `feedback-minimal-3`, retaining on-canvas annotation numbers and object IDs, with explicit region, point and global targets.
- Each moved object stores one final target without repeated geometry; coordinates are integers and scale ratios use at most two decimal places.
- Adds page descriptions, original-image dimensions and SHA-256 verification, and numbered JPEG previews. Desktop, Web, CLI, MCP and video frames share the feedback contract.
- Older feedback and projects remain readable; older applications may not read new v3 feedback.

### Important export change

**Exports now save JSON and a companion original image by default. Deliver them together to AI.** Use `--embed-image` for one self-contained JSON file. `--no-image` retains only the descriptor and requires the receiver to already have the original. `--preview` adds a numbered JPEG, not a replacement for the original.

### Still a focused whiteboard

System screenshots, scrolling capture, pinning, global shortcuts and automatic OCR remain removed. Existing region text in imported files can be retained and edited. Includes the macOS Dock restoration, monochrome menu bar icon and standard drag-and-drop DMG fixes, plus a version-pinned Linux AppImage runtime.

The macOS app remains ad-hoc signed and is not notarized by Apple; Gatekeeper may require permission to open it. Quit the previous version completely before upgrading.
