## 运行与更新

本地白板版从当前源码构建。普通启动显示空白工作台，可粘贴、拖入或导入图片。截图及屏幕权限相关功能已移除。构建见 [开发说明](DEVELOPMENT.md)。上游发行包是原产品，不能用它替代本地精简版。

## 批注编辑

- 顶部工具依次为**智能选块**、**点标注**、**框选**、**调整批注**；其后是**大爆炸**、撤销、重做、**适应图片**、**隐藏 / 显示画面批注**、**全屏**，以及收起批注栏的按钮。默认工具在**设置 → 工具栏 → 默认标注工具**里选。
- 批注栏从一开始就固定预留。点编号或移动箭头，在右侧直接编辑，离开输入框自动保存；右上角加号可添加全局意见。框选松开立即在侧栏输入批注，并保留手动区域供组件调整。窗口变窄时可用批注栏上的按钮收起侧栏。
- 空白处滚轮或 `Ctrl` + 滚轮以鼠标指向的位置缩放整张图片；按住鼠标中键可自由平移，图片比窗口小时也能拖动，并可越过图片四边，普通批注与大爆炸模式一致。`Ctrl + 0` 适应窗口。普通窗口下拖动顶栏，或按住空格 / `Alt` 拖动画面，可移动窗口。
- 调整工具可移动或缩放批注框；单击编号编辑文字。`Ctrl + Z` 撤销，`Ctrl + Y` 重做，`Delete` 删除所选批注。
- 支持打开、拖入或粘贴 PNG / JPEG / WebP / BMP，以及重新打开 `.edithere` 项目或反馈 JSON。
- 关闭批注白板会提示保存未存修改，随后释放截图和切块缓存；程序仍驻留托盘。
- 顶部**眼睛**按钮隐藏画面上的标记，保留右侧批注文字，便于查看原图或导出干净的对比图。

Mac 编辑快捷键使用 Command，重做为 Command + Shift + Z。白板不注册系统全局截图或新建快捷键。

## 视频标注

通过打开文件或拖入视频开始查看，点击“播放”播放视频，点击“暂停”停住画面。拖动时间轴或使用 `−1s` / `+1s` 定位后，停在目标画面：暂停中定位保持暂停，播放中定位后也暂停。普通暂停、首帧和定位仍显示视频，首次实际添加点、框或全局批注才保存截图并进入批注画布；选择模式、缩放和平移不创建截图。再次点击“播放”或按空格继续播放，找到其他时间点后再添加下一组批注。点击时间轴上的青色下尖标签，或从“已标注画面”列表选择，可直接恢复已有截图和批注，空格可控制播放与暂停（在文字输入框中仍输入空格）。

保存 `.edithere` 视频项目会引用源视频地址，内嵌已标注帧的原图和编辑状态。保存项目或导出 JSON 不会把仅暂停查看的画面自动截图加入。源视频移位或丢失后仍可查看保存的截图，点击“重新指定视频”恢复播放。导出 JSON 使用 `video-feedback-1`：每帧包含实际截图时间戳、图片反馈和可选内嵌截图，根对象索引给每个图形标注附 `timestampMs` 与 `frameId`。

时间戳相对源视频起点，坐标为对应帧截图的像素。不同时间点的相同坐标是独立反馈；AI 需要同时读取时间、截图和意见。完整结构、截图文件的分享方式与实际验证记录见 [视频标注说明](VIDEO-ANNOTATION.md)。本轮视频功能实机验收为 Windows，其他平台以各自构建和验收结果为准。

## 大爆炸

点击顶部"大爆炸"按钮，按钮变色，并播放从右上向左下扫过的虹彩波浪。组件直接在**当前窗口**内调整。

首次进入会按识别框切块；再次点击按钮关闭模式时，画面保留调整结果，切块缓存继续保留。重新开启会使用同一套切块及调整数据，不会重新切分；关闭批注白板后才清除缓存。

大爆炸开启时，右侧始终保留批注；点标注工具可在结果上添加意见，编号和移动箭头可直接点击编辑。智能工具用于选块和调整，框选用于补充手动区域；选中组件后可从右侧添加批注。组件调整区固定在侧栏底部，批注列表独立滚动。附着在组件上的批注随组件移动、缩放，编辑结果和批注使用同一套画布坐标。

| 操作 | 行为 |
| --- | --- |
| 未选中时悬停并滚轮 | 遍历包含鼠标的全部候选范围 |
| 单击候选范围 | 选中组件或组件组；已选大框内单击其他区域可切换，拖动仍移动原选区 |
| 拖动已选区域内部 | 移动组件 |
| 拖动边缘中点 | 改变宽度或高度 |
| 拖动角点 | 等比例缩放，无需 Shift |
| 指向已选组件时滚轮 | 等比例放大或缩小组件；指向空白处缩放整图 |
| 右侧 X、Y、宽度、高度、缩放 | 精确设置像素位置、尺寸和比例 |
| 方向键 | 移动 1 px |
| `Ctrl` + 点击 | 多选，选中的块一起拖动或变换 |
| 右键、Esc 或"取消选择" | 返回悬停选块 |
| 底部"框选"后画框 | 添加可操作区域，爆炸前后均可使用 |
| `Ctrl` + 滚轮 | 缩放视图 |

选择大框时，内部组件一起移动、缩放，并保留相对布局；块被移出父组后即脱离父组，父组移动不再带动它。支持撤销和重做。移动后原位置留空，以透明棋盘格显示；不补背景、不恢复被遮挡的内容。调整限制在原图大小的画布内。

移动在发生时即成为一条批注，与文字批注同列并按发生顺序排列，位置不受之后补写文字的影响；它可以没有文字，点开即可补写，编号与画面上的箭头一致。把块移回原位后，没有文字的移动批注一并移除，已写过文字的批注保留。

## 保存与导出

| 操作 | 默认快捷键 | 结果 |
| --- | --- | --- |
| 保存项目 | `Ctrl + S` | `.edithere` 文件，始终内嵌原图与切块缓存，可重新打开继续编辑 |
| 查看 JSON | `Ctrl + E` | 打开反馈预览窗口，可复制或保存 |
| 复制带批注图片 | `Ctrl + C` | 把带批注的画面放进剪贴板；图片区域统一为 960 像素宽，编号、文字与侧栏保持一致比例 |
| 复制 JSON 文件 / 复制 JSON 内容 / 保存图片 / 隐藏标记 / 全局批注 | 默认未绑定 | 可在设置中自行分配 |

底部工具栏默认显示**保存项目**、**保存图片**、**查看 JSON**、**复制 JSON 内容**、**复制 JSON 文件**、**复制带批注图片**、**导入图片**、**适应图片**；显示哪些按钮在**设置 → 工具栏**里勾选，未勾选的按钮不会出现在底栏。

工具栏与批注窗口顶部的**「无法使用？」**给出 Agent 收不下反馈时的处理办法。

**查看 JSON** 窗口提供原图模式、编号示意图与操作：

- **原图：文件引用**（默认）：JSON 与配套原图分别保存，请一起交付；导入验证图片尺寸与 SHA-256。
- **原图：内嵌到 JSON**：适合需要单个自包含文件时使用。
- **原图：不导出**：仅保留尺寸、类型与校验值，接收方必须已有原图。
- **附带标注示意图（JPEG）**：另外输出带编号的预览，不代替原图。
- **压缩内嵌原图 / 示意图**：保持尺寸，可能轻微损失细节。
- **复制 JSON 文件**：把 JSON 写入临时文件并复制该文件（不是复制文本），适用于可以直接发送文件的 Agent；临时目录在**设置 → 默认行为 → 反馈临时目录**中配置。
- **复制 JSON 内容**：复制 JSON 文本，适用于只能粘贴文字的 Agent。
- **保存 JSON 与图片**：把 JSON 与配套图片保存到指定目录。

复制 JSON 与导出 JSON 采用同一种精简结构，字段见[反馈 JSON](#反馈-json)。

## 反馈 JSON

新图片反馈为 `feedback-minimal-3`：每个对象用 `kind` 区分区域、点和全局，有移动的区域记录单个 `movement` 最终目标，意见为保留界面编号的 `{number,text}` 数组。旧 `movements`、字符串意见和未版本化反馈仍可读取。视频反馈在 `frames[].feedback` 内复用这份结构，并补充帧时间戳、源视频信息和带时间戳的对象索引，详见 [视频标注](#视频标注)。

| 字段 | 含义 |
| --- | --- |
| `image` | 原图描述：`file`（默认）、`embedded` 或 `none`；包含类型、尺寸和 SHA-256 |
| `annotationSpace` | 固定为 `"result"`，表示批注坐标对应当前调整后的画面 |
| `objects[].id / kind` | 图片内对象 ID，以及 `region`、`point`、`global` 类型 |
| `objects[].source / point` | 区域使用正尺寸 `source`，点使用 `point:{x,y}`，全局不带坐标 |
| `objects[].movement` | 可选最终 `rect`、累计 `dx/dy`、非单位 `scaleX/scaleY` |
| `objects[].annotations` | `{number,text}` 意见数组，编号对应界面，不按对象位置重新编号 |

没有意见、没有变化的组件不导出；不输出完整切片清单或组件组引用。反馈含实际工具版本、带时区导出时间及原图校验值。原图 Base64 会增加文件体积，这是把图片放进单个 JSON 的数据开销，与组件数量无关。图片格式由 `schema/feedback-minimal.schema.json` 定义；视频反馈和项目分别由 `schema/video-feedback-v1.schema.json`、`schema/video-project-v1.schema.json` 定义。

坐标以画布左上角为原点，单位为图像像素，与窗口位置和视图缩放无关。框使用 `x1/y1/x2/y2` 两个端点；右下边界不包含自身，宽高为 `x2-x1`、`y2-y1`。新反馈坐标和位移均为整数，缩放最多两位小数、缺省为 1；项目内部保留精度，旧反馈的小数仍可读取。

以下是**仍可读取的旧格式示例，不是新导出格式**；当前 v3 的完整字段与示例见 [AI 与命令行](AGENT-CLI.md) 和 [反馈 v3](FEEDBACK-V3.md)：

```json
{
  "annotationSpace": "result",
  "objects": [
    {"source": {"x1": 240, "y1": 180, "x2": 240, "y2": 180},
     "movements": [], "annotations": ["这里改为蓝色"]},
    {"source": {"x1": 200, "y1": 140, "x2": 400, "y2": 240},
     "movements": [], "annotations": ["增加圆角"]},
    {"source": {"x1": 100, "y1": 100, "x2": 300, "y2": 200},
     "movements": [{"to": {"x1": 200, "y1": 140, "x2": 400, "y2": 240}}],
     "annotations": ["整块往右下挪一点"]},
    {"source": null, "movements": [], "annotations": ["整体更轻盈、安静，减少装饰"]}
  ]
}
```

还原结果时，先从原图提取每个对象的 `source` 区域并将原位置留空，再按 `movements` 顺序绘制到 `to`；最后在结果上解释或绘制批注。未移动的区域保持原样。

早期版本使用的 `annotations` 与 `changes` 并行数组（旧格式）仍可导入，导入后按来源区域合并为对象结构：

| 格式 | 原图 | 批注坐标 | 布局信息 |
| --- | --- | --- | --- |
| 0.5 及以前的 v1/v1.1/v2 项目 | `capture.pngBase64` 可内嵌，或引用外部 PNG | 原图 | v2 保存全部切片、分组及原始/目标坐标 |
| 0.6 精简反馈 | 外部同名 PNG | 原图 | 仅变化的 `from/to` |
| 0.7 / 0.8 反馈 | `image` 可内嵌 | 调整后的画面 | `changes` 中仅变化的 `from/to` |
| 0.9 起的旧对象反馈 | `image` 可内嵌 | 调整后的画面 | `source` 与旧 `movements` |
| 当前 v3 反馈 | 默认配套图片，也可内嵌 | 调整后的画面 | `kind`、单个 `movement`、编号意见 |
| 3.0.0 `.edithere` 项目 | 始终内嵌原图 | 调整后的画面 | 完整切块缓存和当前编辑状态 |

应用不再打开旧版项目及 0.6 精简反馈，旧批注不再转换到调整结果的位置。取消包含原图时，重新打开需要配套的同名原图 PNG。`.edithere` 项目保存完整切块及编辑状态（`schemaVersion: "3.0.0"`），重新打开直接恢复。关闭白板会释放内存缓存。重新打开反馈 JSON 时，从原图和其中的变化重建布局。

## 设置

右键任务栏右下角的 EditHere 托盘图标，选择"设置"。窗口包含"快捷键""外观""默认行为""工具栏"和"关于与更新"五个页签。点击"保存"应用设置；快捷键和外观立即生效，默认工具与缩放用于下一张图片，启动行为用于下次启动。"取消"不改变当前配置。

### 外观

- **外观模式**：跟随系统、亮色、暗色，默认为跟随系统。切换后，编辑器、批注栏、组件侧栏、菜单和设置窗口统一更新；原图与导出图片的原始像素不受主题影响。
- **界面语言**：跟随系统、简体中文、English。切换后立即预览，保存后生效，取消则回到原来的语言。系统的文件对话框、消息框与颜色选择器一并跟随。导出给 AI 的 JSON 字段值不随界面语言变化。

### 默认行为

| 选项 | 说明 |
| --- | --- |
| 开机时启动 EditHere | 登录系统后仅驻留托盘，不自动截图；需保留程序所在文件夹，移动后重新保存一次即可刷新路径 |
| 打开图片时自动适应窗口 | 关闭后以 100% 显示，仍可随时缩放或使用适应窗口 |
| 原图导出模式 | 文件引用（默认）、内嵌 JSON 或不导出；保存项目始终内嵌原图 |
| 附带标注示意图 | 另外生成编号 JPEG |
| 导出时附带区域文字 / 窗口标题 | 控制已有导入信息的导出；不启用 OCR 或窗口采集 |
| 关闭批注窗口时询问是否保存 | 关闭后不再弹窗，直接放弃未保存的批注；在批注窗口勾选「不再提醒」也会关掉这一项 |
| 反馈临时目录 | 反馈 JSON 临时文件的保存位置，留空使用默认缓存目录下的 `feedback` |

Windows 使用当前用户的启动项，无需管理员权限。免安装版启用后请保留程序所在文件夹；如果 Windows 已禁用该启动项，程序会提示到系统启动应用设置中手动恢复，不会强行修改系统禁用状态。Mac 使用系统登录项，若系统要求批准会明确提示；Mac 仍未实机验收。

### 工具栏

- **默认标注工具**：智能选块、点标注、框选标注、调整批注，决定打开图片后默认选中的工具。
- **显示在底部工具栏**：保存项目、保存图片、查看 JSON、复制 JSON 内容、复制 JSON 文件、复制带批注图片、导入图片、适应图片。取消勾选即从底栏移除，功能仍可通过快捷键或菜单使用。

### 诊断日志

遇到问题后，打开 **设置 → 诊断日志**，点击 **导出诊断日志…**，将导出的文本文件、复现步骤和问题发生时间一起反馈。**打开日志目录**可直接查看自动保存的 JSONL 日志。日志记录版本、系统与 Qt 环境、截图尺寸、操作状态及错误，不记录截图、视频或批注正文，不会自动上传。

默认每个日志文件最多 1 MiB，保留近期 10 个文件；同时运行的进程日志受到保护，退出后恢复限额。导出的单份报告最多 4 MiB，包含近期日志和运行环境。日志使用当前用户的数据目录：Windows 为 `%LOCALAPPDATA%/EditHere/EditHere/logs`，macOS、Linux 使用各自的 Qt `AppLocalDataLocation`。程序启动时会记录前次未正常结束的会话；这可能来自崩溃、强制结束或写入失败，不能单凭该记录确定原因。日志会过滤用户主目录、URL 查询参数和常见密钥字段，分享前仍可自行检查。

### 关于与更新

显示当前版本与许可说明。可勾选**启动时检查更新**，或点击**检查更新**手动检查；发现新版本后按钮变为**立即更新**，详见[构建说明](DEVELOPMENT.md)。**使用引导**按钮会关闭设置并从头播放引导，未保存的设置不会保存；**恢复默认**重置当前设置草稿，仍需保存才生效。

设置保存在当前用户的 Qt `AppConfigLocation/settings.ini`，关闭程序后仍保留。Windows 默认位置为 `%LOCALAPPDATA%/EditHere/EditHere/settings.ini`；Mac 由系统配置目录决定。

## 使用引导与开机自启

- 普通启动显示空白白板，不自动展示引导。手动打开引导时使用示例或保留当前图片。右上角 **?** 和设置底部的 **使用引导** 均可从头开始。引导可前后翻页，Esc 只退出引导。
- 引导状态与设置偏好分开保存，恢复默认设置不会让引导反复出现。从设置重看引导会关闭设置窗口，不保存尚未应用的修改。

## 与 AI 配合使用

你可以手动复制 JSON，也可以让接入 CLI 的 AI 发起标注会话。后一种方式中，AI 打开图片，你添加批注或调整组件，最后点击顶部 **"完成并返回 AI"**；CLI 此时才导出本轮反馈并返回成功。点击"取消"或等待超时不提交反馈，编辑器保留当前文档。连接中断时结果可能不明，需核查本轮是否已经完成，不能直接重复发起会话。

每轮反馈使用新的输出文件，AI 只读取本轮明确提交的结果，不能将之前的文件当作新意见。配套 skill 的安装、命令和示例见 [AI 与命令行](AGENT-CLI.md)。

## 识别与平台边界

智能选块分析用户导入图片中的颜色、边缘及网格，不需要模型或网络。没有识别到目标时，可以手动画框。系统截图、OCR 和辅助功能元素识别已移除，因此不申请屏幕录制或辅助功能权限。
